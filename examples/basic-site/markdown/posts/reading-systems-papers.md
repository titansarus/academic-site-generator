Reading systems papers well is a skill you can practice. Here is my routine.

## The three-pass method

- **Pass 1:** title, abstract, figures. Decide if it is worth more time.
- **Pass 2:** read for the main idea and the evaluation setup.
- **Pass 3:** reproduce the argument; note assumptions and threats to validity.

Keep a running note per paper with three lines: the problem, the key idea, and
what you would do differently.
